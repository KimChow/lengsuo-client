# AnyTLS 实现与验收状态

协议参考基线：anytls-go 完整 commit
`fd6167acd6d73b9fa3e607659951847fbc9e6c50` 中的 `docs/protocol.md`
与 `proxy/session/frame.go`，协议版本 2。

已实现认证原语：SHA256 密码摘要、两字节 padding 长度、容量限制内完整读取
padding 后常量时间认证。调用方必须先建立经过服务器身份验证的 TLS。
所有异步读写具备正数截止时间，无认证失败明文回退。

已实现 11 个命令的帧编解码，四字节大端 Stream ID、两字节大端数据长度；
禁止不允许载荷的 SYN、FIN 和心跳帧携带数据。异步读取先检查容量上限。
认证对象与数据帧均不派生 Debug，避免凭据或应用载荷意外进入日志。
任何流操作失败后调用方必须丢弃该连接，不得在未对齐的流上继续读取。

五项真实测试覆盖 SHA256 固定向量及 padding 边界、固定帧字节及全部截断、
命令约束及最大长度、错误密码/认证截断/容量/超时，以及帧异步异常。

尚未实现会话状态机、Settings 协商、单调 Stream ID、SYNACK、流复用、
心跳处理、padding 策略更新、空闲池和 UDP-over-TCP v2。
原语测试不能代表上述功能或参考互通通过，不得作为可用代理发布。
双向参考连接、完整异常验证与浏览器环境隔离仍属于最终交付范围。
