# VLESS 实现与验收状态

参考基线为 Xray v26.3.27，完整 commit：
`d2758a023cd7f4174a5a5fa4ff66e487d4342ba0`。

## 已实现

- v0 基础 TCP/UDP 请求头编码及增量解析，共用目标地址内存模型。
- 地址使用 VLESS 自身的端口在前格式，IPv4=1、域名=2、IPv6=3。
- 明确返回头部消耗长度，保留后续应用载荷；用户标识不放入 Debug 请求对象。
- 拒绝不支持的版本、命令和非空附加字段；域名拒绝空值、NUL 和超长值。
- 四项单元测试覆盖固定字节向量、地址编号、全部截断位置和非法输入。

## 尚未完成

- 当前只有请求头编解码，尚无认证、异步连接和响应头处理。
- UDP 数据帧、Vision、Mux、反向代理及其他外层传输尚未实现。
- 编解码本身不提供加密；正式运行必须在认证安全传输中使用。
- Rust 双向连接、Xray 双向 TCP/UDP、错误凭据、半关闭及超时仍待验证。
- 四项单元测试不代表参考实现互通，未完成协议不得作为可用服务发布。
- Windows 浏览器环境隔离与 TUN 完整验收仍属于最终交付要求。

核验依据为参考源码 `proxy/vless/encoding/encoding.go`、
`common/protocol/payload.go` 与本仓 `header.rs` 测试。
