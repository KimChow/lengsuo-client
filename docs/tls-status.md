# TLS 传输实现状态

本模块提供基于 TCP 的标准认证 TLS，不属于浏览器 TLS 指纹模拟，也不代表代理协议互通已经通过。

- 客户端使用显式信任根并校验服务器身份；空信任库、非法主机名及零超时配置均拒绝。
- 同一个截止时间覆盖 TCP 连接和 TLS 握手；服务端握手也有明确超时。不存在明文回退或跳过证书验证接口。
- 服务端当前不提供双向 TLS；上层应用协议仍必须完成认证。
- 显式选择 ring 提供方，避免其他工作区组件启用不同提供方时造成默认配置歧义。
- 五个真实回环测试覆盖加密往返、错误主机名、不可信证书、静默对端超时和非法配置。证书仅在测试运行时生成。
- 自有生产代码禁止 unsafe；依赖使用其常规密码及系统实现。已检查直接依赖的许可证，不宣称许可证审查已自动纳入 CI。
- Windows 原生构建、浏览器隔离以及各代理协议的参考实现互通属于独立验收项目。
