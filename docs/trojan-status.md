# Trojan 实现与验收状态

基线为 Xray v26.3.27 完整 commit
`d2758a023cd7f4174a5a5fa4ff66e487d4342ba0`，参考 `proxy/trojan/protocol.go`。

已实现密码 SHA224 小写十六进制请求头认证、TCP/UDP 命令和 SOCKS 目标地址，
地址复用 ss-core 的检查编码和解码。认证使用常量时间比较，解析返回精确头部
消耗长度，截断、错误凭据、CRLF、非法命令及地址分别失败。Credential 的手写
Debug 始终输出脱敏占位符，不输出密码或摘要。目标地址日志仍受隐私策略约束。

Claude Code 产出基础编解码与十一项测试，在轮次上限后由集成负责人接管。
十一项测试实际通过：SHA224 固定已知向量、固定请求字节、IPv4/域名/IPv6、
UDP 命令、全部截断、错密码、坏 CRLF、非法命令/地址、域名限制、载荷边界
及凭据 Debug 不泄漏。复核修正 CRLF 常量的 Clippy 警告后纳入严格门禁。

新增两项固定 Xray v26.3.27 的 TLS 参考测试已实际通过：Rust 请求编码端→
Xray 服务端，以及 Xray 客户端→Rust 请求解码端，IPv4 TCP 二进制载荷一致。
运行时生成测试证书并显式信任，不跳过证书验证；错误主机名和不可信证书拒绝。
当前测试直接调用基础 codec 并使用有超时的测试读写适配，尚不代表产品异步
入站/出站流水线已经集成。参考启动日志不输出凭据和带私钥的配置。

```sh
LENGSUO_XRAY=/绝对路径/xray cargo test -p lengsuo-trojan --locked --test xray_tls -- --ignored --nocapture
```

默认测试忽略这两项，必须显式执行才能声明该范围参考互通通过。
尚未实现产品异步握手、UDP 帧与参考互通、全部异常路径。
本模块必须在经过服务器身份验证的 TLS 之上使用，不能作为裸 TCP 产品服务。
这些原语测试不代表协议服务或浏览器网络验收完成。
