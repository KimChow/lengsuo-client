# 网络开发任务与验收

确认日期：2026-10-15。用户已授权 Rust 自主实现与多个 Claude Code 并行开发；本批能力集中在 lengsuo-client，不创建协议仓。产品参考、自主设计、兼容性验证为统一表述。

## 范围和接口

- 协议：VLESS、VMess、Trojan、Shadowsocks、Shadowsocks-2022、Hysteria 2、WireGuard、AnyTLS。
- 协议库提供可组合的客户端/出口侧接口；共享目标地址复用 ss-core::target::TargetAddr。TCP 流、UDP 会话、IP 包语义分别处理。
- 每个协议单独 crate；公共工作区、ss-core API、锁文件由集成负责人维护，任务不得相互改写。
- 同域名多出口按环境身份选择设备，不能依赖全局域名/IP规则或仅靠进程名。连接、DNS状态、凭据与连接池按环境和配置版本隔离。
- TUN 原始包不携带可信环境身份；接入层必须使用可信入口绑定或平台隔离上下文，不能凭空声称从包中取得 PID/环境。
- 受管流量无映射、设备离线、配置失效即拒绝；非受管应用、模型、SSH不受影响。设备切换终止旧会话，不静默直连。
- VPS 工具仅负责节点配置和数据面生命周期；平台权限、账单、客户秘密不进入本仓。
- 先做可测试的协议与运行时，再接入平台设备与浏览器；Windows 特有接入不得冒充已由 Linux 测试验证。

## 工作线

八协议各有独立 worktree；环境运行时、TUN 接入、VPS 工具另有三条工作线。每条仅修改分配 crate 和对应文档，独立提交。不得推送、合并默认分支或更改系统安全设置。

共用基础设施由主理人维护；每条工作线对实际支持的算法、版本、传输、安全层和异常行为记录清单，未支持项明确保留，不通过 stub、mock 或自家 roundtrip 冒充互通。

## 兼容性与证据

Xray 初始候选 v26.3.27；必须先锁定完整 commit，并核验每协议是否存在对应能力。AnyTLS 使用 anytls-go 固定 commit 作为额外对照。Hysteria、WireGuard 可补各自官方固定版本。

测试覆盖确定性字节向量、截断、错误密码、篡改、重放（适用时）、边界长度、半关闭、超时及清理；网络测试仅回环或专用隔离网络、假凭据。

完整协议验收需 Rust↔Rust、Rust客户端↔参考服务端、参考客户端↔Rust服务端；不支持该协议的参考版本必须如实说明并补对照，不能跳过。

环境验收：A/B/C访问同域名和同IP分别使用指定设备；DNS/IPv6/UDP分开；A断线不影响B/C且无直连；停止、重启和身份复用无串流；非受管流量不变。

## 构建与集成

- dev/release/test与构建依赖的 debug=0，strip=debuginfo；关闭本批增量缓存，产物放仓库外。
- 每个 worktree 独立 target；本批重型编译先限4个并发，每任务 cargo jobs=2，禁止同一 target 并发 Cargo。
- 不删除旧项目target、不停止无关进程。临时产物仅清理本轮已核实路径。
- 700行硬上限、400行软目标继续生效；禁用 unsafe 生产网络代码，不新增GPL/AGPL/SSPL链接依赖。
- 集成负责人运行行数、fmt、clippy、locked tests和build；功能提交集成后重新验证，再更新默认分支，推送后核对完整SHA。
- 当前原始基线只有ss-core部分原语和客户端骨架，尚无八协议及TUN完整验收；本文件是任务规格，不是完成报告。

## 2026-10-17 调度纠偏与分批验收

此前大任务反复续接旧上下文，单任务90～130次工具调用仍主要在重复搜索。
停止重复探索会话并保留现场；后续使用干净上下文，不靠增加轮次解决任务设计问题。
完整目标仍是八协议双向互通、异常路径、Windows指定浏览器环境TUN端到端。

启动前由主会话确认：固定基线、参考完整commit、实际可执行工具及路径、依赖缓存、
模型工具调用、基线结果。环境故障与产品错误分开，依赖下载失败不交给模型反复绕过。

### DNS 显式上游交换（本批验收）

新增独占 UDP socket 的显式上游请求与响应校验，拒绝错误 ID、问题区或来源，具备总超时且不回退系统 DNS。问题名采用严格字节回显匹配（含大小写），不承诺接受上游改写问题区大小写。修复未压缩问题名的长度字节与根标签解析，覆盖原始编码和类型边界。此项只是 DNS 数据交换原语，不代表浏览器 TUN 完整数据通路已通过。

### Hysteria UDP 消息层验收

新增官方 UDPMessage 格式的借用式编解码，覆盖原始地址字节、非最短 varint、边界和截断等 18 项测试。固定参考为 apernet/hysteria `ca8fbd874fd6ca82413948de6dc5924405e103e1` 的 `core/internal/protocol/proxy.go`；协调端另用 Python struct.pack 核对黄金样本。此项不代表 QUIC、HTTP/3 认证、分片重组或真实进程互通已完成；既有 CONNECT-UDP capsule 不计入官方 Hysteria2 兼容范围。

### SS2022 TCP 反向互通验收

固定 Xray `d2758a023cd7f4174a5a5fa4ff66e487d4342ba0` 客户端经 SOCKS 入站连接 Rust 接收方，再中继至独立回环 echo；AES-128/256 各验证 1、512、1200 字节请求和回程，覆盖响应头后续 chunk 与关闭写半。测试辅助按职责拆分，修复短载荷切片越界与 SOCKS 响应域名长度读取。该正常载荷互通测试不证明全部恶意输入、重启重放保护或完整生产运行时已验收。
